Wi-Fi Security Guardian for Windows
===================================

How to run
1. Keep all files in this folder together (the .exe needs the .dll files and the "data" folder).
2. Double-click WiFiSecurityGuardian.exe.
3. If Windows SmartScreen says "Windows protected your PC", click "More info" and then "Run anyway".
   The app is not code-signed; this warning is normal for apps shared outside the Microsoft Store.
4. If Windows Firewall asks for permission, allow access on "Private networks" so device discovery works.

Good to know
- The app scans the network this PC is connected to (Wi-Fi or cable).
- Only scan networks you own or have permission to test.
- Everything stays on this PC. Scan results, history and device names are never uploaded.
- To uninstall, delete this folder.
